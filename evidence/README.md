# Curated Evidence

This directory contains the minimum publication-safe evidence needed to support
the final Project Janus claims.

- `deployment/` — successful Suricata syntax, reload, hash, and SID publication
  output.
- `response/` — minimized alert, blocklist-response, and firewall evidence.
- `validation/` — concise IT and OT attack/baseline validation summaries.

Raw PCAPs, EVTX exports, full EVE/firewall logs, and full normalized datasets
are intentionally excluded because they contain unnecessary host, path, packet,
and user metadata. Their original SHA-256 manifests and working copies should
remain in controlled project storage.
